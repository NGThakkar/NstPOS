1. Overview

What is this task?

This task helps Admin users toggle account status for workforce changes in CrazyPOS. It is structured to keep operations consistent, policy-aligned, and easy to audit.

When to use this task

Use this task staff leave, return, or are temporarily suspended.

Key benefits

  • Protect system from unused active accounts
  • Enable quick reinstatement when needed
  • Maintain accurate user roster

2. Prerequisites

Before you begin, ensure you have:

  • [ ] Admin status-management permission
  • [ ] Target account identified
  • [ ] HR/manager instruction available

Required information to gather

  • Username
  • Requested status change
  • Effective date and reason

3. Step-by-Step Instructions

Step 1: Access the correct module

Open user account status management and find the target user profile.

  1. Sign in with your Admin account.
  2. Open User Administration and locate the account.
  3. Confirm employee identity before status change.

Tip: Verify filters and context before editing any records.

SCREENSHOT: Landing screen for Deactivate or Reactivate Users

Step 2: Enter required details

Select deactivate or reactivate action

  1. Select the user account to deactivate/reactivate.
  2. Choose Deactivate or Reactivate action.
  3. Enter effective reason/comment per policy.

Important: Incorrect values can cause policy or reconciliation issues.

SCREENSHOT: Data entry and selection fields for Deactivate or Reactivate Users

Step 3: Validate the result

Enter reason/comment if required

  1. Review session and policy warnings before status change.
  2. Verify whether active sessions need forced logout.
  3. Confirm account is not system-protected.
SCREENSHOT: Validation panel with totals and status checks

Step 4: Submit and confirm

Save and confirm status update

  1. Confirm status-change action in the prompt.
  2. Save status change and verify account flag update.
  3. Record change in access-control review log.
