1. Overview

What is this task?

This task helps Manager users approve and settle pending return refunds in CrazyPOS. It is structured to keep operations consistent, policy-aligned, and easy to audit.

When to use this task

Use this task after returns are created and queued for payout.

Key benefits

  • Control refund authorization
  • Keep cash/card reconciliation accurate
  • Close return cases faster

2. Prerequisites

Before you begin, ensure you have:

  • [ ] Manager approval rights are active
  • [ ] Pending refund queue is accessible
  • [ ] Payment method rules are known
  • [ ] Cash drawer/card settlement channel is available

Required information to gather

  • Return ID
  • Refund amount
  • Settlement method

3. Step-by-Step Instructions

Step 1: Access the correct module

Open the pending refunds queue for returns and prepare the settlement view.

  1. Sign in with your Manager account.
  2. Open Returns and navigate to Pending Refunds.
  3. Confirm branch filter and settlement date are correct.

Tip: Verify filters and context before editing any records.

SCREENSHOT: Landing screen for Settle Pending Refunds for Returns

Step 2: Enter required details

Review each return and verify amount/method

  1. Select a pending refund entry from the settlement queue.
  2. Verify refund amount, reason, and payment channel.
  3. Confirm return status is approved for settlement.

Important: Incorrect values can cause policy or reconciliation issues.

SCREENSHOT: Data entry and selection fields for Settle Pending Refunds for Returns

Step 3: Validate the result

Approve and settle refund transaction

  1. Review refund amount, channel status, and risk warnings.
  2. Validate payout method against policy limits.
  3. Resolve mismatches before approving payout.
SCREENSHOT: Validation panel with totals and status checks

Step 4: Submit and confirm

Confirm status changes to settled and log reference

  1. Confirm settlement action for the selected refund.
  2. Confirm settlement status changes to Settled.
  3. Record settlement reference for reconciliation.
SCREENSHOT: Success message with generated reference
