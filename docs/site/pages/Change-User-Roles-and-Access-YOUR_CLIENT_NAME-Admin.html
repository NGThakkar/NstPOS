1. Overview

What is this task?

This task helps Admin users modify user role and permission scope in CrazyPOS. It is structured to keep operations consistent, policy-aligned, and easy to audit.

When to use this task

Use this task job responsibility changes or temporary elevated access is needed.

Key benefits

  • Keep least-privilege model enforced
  • Reduce unauthorized operations
  • Maintain controlled operational access

2. Prerequisites

Before you begin, ensure you have:

  • [ ] Admin role-permission rights
  • [ ] Updated access approval available
  • [ ] User account exists and active

Required information to gather

  • Target username
  • New role/access scope
  • Approval reference

3. Step-by-Step Instructions

Step 1: Access the correct module

Open user permissions and select the role-access assignment view.

  1. Sign in with your Admin account.
  2. Open User Roles and Permissions.
  3. Confirm target user and organizational scope.

Tip: Verify filters and context before editing any records.

SCREENSHOT: Landing screen for Change User Roles and Access

Step 2: Enter required details

Open role/access assignment section

  1. Select target user account for role update.
  2. Select new role template and permitted modules.
  3. Set branch scope and optional access expiry.

Important: Incorrect values can cause policy or reconciliation issues.

SCREENSHOT: Data entry and selection fields for Change User Roles and Access

Step 3: Validate the result

Apply new role, scope, and optional expiration

  1. Review permission-delta summary and governance alerts.
  2. Compare old vs new permissions for risk checks.
  3. Validate approval reference if required.
SCREENSHOT: Validation panel with totals and status checks

Step 4: Submit and confirm

Save and confirm effective permissions

  1. Confirm and apply updated role/access configuration.
  2. Save changes and confirm role update timestamp.
  3. Ask user to re-login to refresh permissions.
