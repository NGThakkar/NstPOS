1. Overview

What is this task?

This task helps Cashier users submit a validated sales return for accepted items in CrazyPOS. It is structured to keep operations consistent, policy-aligned, and easy to audit.

When to use this task

Use this task after preview confirms return details and refund eligibility.

Key benefits

  • Create auditable return records
  • Ensure stock and finance updates align
  • Speed up counter return processing

2. Prerequisites

Before you begin, ensure you have:

  • [ ] Return preview completed successfully
  • [ ] Customer and sale reference are confirmed
  • [ ] Cashier has return submission rights
  • [ ] Return reason codes are available

Required information to gather

  • Preview/session reference
  • Approved return lines and quantities
  • Customer acknowledgment if required

3. Step-by-Step Instructions

Step 1: Access the correct module

Open the sales return module and start the return workflow screen.

  1. Sign in with your Cashier account.
  2. Open Returns and select Create Return.
  3. Confirm store context and cashier shift are correct.

Tip: Verify filters and context before editing any records.

SCREENSHOT: Landing screen for Create a Sales Return

Step 2: Enter required details

Confirm item lines, quantities, and reasons

  1. Select the prepared return preview or source sale record.
  2. Load the saved preview or original sale reference.
  3. Confirm item quantities and line-level reason codes.

Important: Incorrect values can cause policy or reconciliation issues.

SCREENSHOT: Data entry and selection fields for Create a Sales Return

Step 3: Validate the result

Submit return and capture generated return ID

  1. Review final return totals and submission warnings.
  2. Validate final refund total and approval requirements.
  3. Resolve blocked lines before submitting return.
SCREENSHOT: Validation panel with totals and status checks

Step 4: Submit and confirm

Hand off refund for settlement if needed

  1. Click Submit Return to post the return transaction.
  2. Confirm return ID is generated successfully.
  3. Send return to refund-settlement queue if required.
SCREENSHOT: Success message with generated reference
