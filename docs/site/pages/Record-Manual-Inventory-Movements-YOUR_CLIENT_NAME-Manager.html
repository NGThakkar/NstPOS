1. Overview

What is this task?

This task helps Manager users record non-sale inventory movements such as damage, transfer, or correction in CrazyPOS. It is structured to keep operations consistent, policy-aligned, and easy to audit.

When to use this task

Use this task when stock changes outside regular sales and receiving.

Key benefits

  • Keep inventory ledger complete
  • Improve traceability of stock changes
  • Support audit and reconciliation

2. Prerequisites

Before you begin, ensure you have:

  • [ ] Movement-entry permission is enabled
  • [ ] Movement types are configured
  • [ ] Target items and quantities are known

Required information to gather

  • SKU/item
  • Movement type
  • Quantity and notes

3. Step-by-Step Instructions

Step 1: Access the correct module

Open manual movement entry and prepare the stock movement form.

  1. Sign in with your Manager account.
  2. Open Inventory Movements and select Manual Entry.
  3. Confirm movement date and store location.

Tip: Verify filters and context before editing any records.

SCREENSHOT: Landing screen for Record Manual Inventory Movements

Step 2: Enter required details

Select movement type and target item

  1. Select item and movement type for manual posting.
  2. Choose movement type (damage, transfer, correction, etc.).
  3. Select item and enter quantity with reference note.

Important: Incorrect values can cause policy or reconciliation issues.

SCREENSHOT: Data entry and selection fields for Record Manual Inventory Movements

Step 3: Validate the result

Enter quantity, reference, and reason notes

  1. Review movement direction and quantity validation.
  2. Verify movement direction and resulting stock effect.
  3. Confirm reason code and document reference are valid.
SCREENSHOT: Validation panel with totals and status checks

Step 4: Submit and confirm

Submit movement and verify ledger update

  1. Submit movement entry and confirm posting.
  2. Save movement and check ledger entry timestamp.
  3. Verify updated quantity in item stock card.
SCREENSHOT: Success message with generated reference
