1. Overview

What is this task?

This task helps Admin users create, update, and maintain staff user accounts securely in CrazyPOS. It is structured to keep operations consistent, policy-aligned, and easy to audit.

When to use this task

Use this task onboarding new staff or updating account details.

Key benefits

  • Ensure each user has unique credentials
  • Improve access governance
  • Reduce security and audit risks

2. Prerequisites

Before you begin, ensure you have:

  • [ ] Admin user-management rights
  • [ ] Required staff profile details
  • [ ] Password policy rules available
  • [ ] Role matrix approved

Required information to gather

  • Employee name/ID
  • Username/email
  • Initial role and branch assignment

3. Step-by-Step Instructions

Step 1: Access the correct module

Open user administration and navigate to the account management screen.

  1. Sign in with your Admin account.
  2. Open User Administration and select Accounts.
  3. Confirm tenant/store scope before editing users.

Tip: Verify filters and context before editing any records.

SCREENSHOT: Landing screen for Create and Maintain User Accounts

Step 2: Enter required details

Create new account or edit existing profile

  1. Select existing user profile or click Create User.
  2. Enter username, profile details, and initial role.
  3. Set branch access and account status.

Important: Incorrect values can cause policy or reconciliation issues.

SCREENSHOT: Data entry and selection fields for Create and Maintain User Accounts

Step 3: Validate the result

Assign base role, branch scope, and status

  1. Review role, branch scope, and security-policy warnings.
  2. Check password policy and uniqueness warnings.
  3. Validate role assignment against access matrix.
SCREENSHOT: Validation panel with totals and status checks

Step 4: Submit and confirm

Save and validate login readiness

  1. Save user profile changes.
  2. Save account and confirm user appears in directory.
  3. Trigger reset/invite flow if required by policy.
SCREENSHOT: Success message with generated reference
