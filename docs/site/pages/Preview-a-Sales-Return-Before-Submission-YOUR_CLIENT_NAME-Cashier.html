1. Overview

What is this task?

This task helps Cashier users review return lines, quantities, and refund totals before final submission in CrazyPOS. It is structured to keep operations consistent, policy-aligned, and easy to audit.

When to use this task

Use this task before posting a return to avoid incorrect refunds.

Key benefits

  • Catch quantity and price mistakes early
  • Reduce refund disputes at counter
  • Improve first-pass accuracy of return processing

2. Prerequisites

Before you begin, ensure you have:

  • [ ] Original sale reference or receipt is available
  • [ ] Cashier has return module access
  • [ ] Returnable items and quantities are identified
  • [ ] Reason code policy is known

Required information to gather

  • Original transaction ID
  • Items to be returned and quantities
  • Return reason code

3. Step-by-Step Instructions

Step 1: Access the correct module

Open the return preview module and load the screen for the target sale.

  1. Sign in with your Cashier account.
  2. Open Returns and choose Preview Return.
  3. Confirm the branch and terminal context matches the original sale.

Tip: Verify filters and context before editing any records.

SCREENSHOT: Landing screen for Preview a Sales Return Before Submission

Step 2: Enter required details

Load original sale and mark items/quantities for return

  1. Search and load the original sale by transaction ID or receipt.
  2. Mark returnable items and adjust quantities to be returned.
  3. Select the return reason code for each line.

Important: Incorrect values can cause policy or reconciliation issues.

SCREENSHOT: Data entry and selection fields for Preview a Sales Return Before Submission

Step 3: Validate the result

Validate refund totals, tax adjustments, and policy warnings

  1. Review subtotal impact, refund value, and warning banners.
  2. Verify tax reversal and discount carryover from the original sale.
  3. Resolve policy warnings before saving preview.
SCREENSHOT: Validation panel with totals and status checks

Step 4: Submit and confirm

Save preview and proceed to create return if details are correct

  1. Click Save Preview to store the prepared return.
  2. Confirm preview is saved and linked to the sale reference.
  3. Continue to Create Sales Return when details are correct.
