1. Overview

What is this task?

This task helps Manager users review low-stock alerts and stock performance metrics in CrazyPOS. It is structured to keep operations consistent, policy-aligned, and easy to audit.

When to use this task

Use this task daily or before replenishment decisions.

Key benefits

  • Prevent stockouts
  • Prioritize replenishment efficiently
  • Improve service levels for top-selling items

2. Prerequisites

Before you begin, ensure you have:

  • [ ] Inventory dashboard access
  • [ ] Low-stock thresholds configured
  • [ ] Branch filter selected

Required information to gather

  • Low-stock list
  • Days of stock metric
  • Recent sales velocity

3. Step-by-Step Instructions

Step 1: Access the correct module

Open low-stock analytics and load the inventory statistics dashboard.

  1. Sign in with your Manager account.
  2. Open Inventory Analytics and select Low-Stock view.
  3. Confirm branch and date period filters.

Tip: Verify filters and context before editing any records.

SCREENSHOT: Landing screen for Review Low-Stock Items and Inventory Stats

Step 2: Enter required details

Filter by branch/category and review flagged items

  1. Select relevant low-stock records from the dashboard list.
  2. Apply category/brand filters and inspect flagged SKUs.
  3. Review days-of-stock and sales velocity columns.

Important: Incorrect values can cause policy or reconciliation issues.

SCREENSHOT: Data entry and selection fields for Review Low-Stock Items and Inventory Stats

Step 3: Validate the result

Prioritize items by velocity and threshold breach

  1. Review alert severity, turnover, and threshold indicators.
  2. Prioritize critical items by threshold breach and demand.
  3. Confirm min/max stock settings are configured correctly.
SCREENSHOT: Validation panel with totals and status checks

Step 4: Submit and confirm

Export or share list for replenishment action

  1. Finalize export/share action for replenishment planning.
  2. Export low-stock list for replenishment planning.
  3. Share action list with purchasing or store ops.
