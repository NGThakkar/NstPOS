1. Overview

What is this task?

This task helps Manager users void a completed sale under approved policy in CrazyPOS. It is structured to keep operations consistent, policy-aligned, and easy to audit.

When to use this task

Use this task when a completed transaction must be reversed due to error or compliance requirement.

Key benefits

  • Correct financial records quickly
  • Prevent downstream reconciliation issues
  • Maintain clear audit trail of reversals

2. Prerequisites

Before you begin, ensure you have:

  • [ ] Manager cancel permission is enabled
  • [ ] Target transaction can be identified
  • [ ] Cancellation reason policy is available
  • [ ] Accounting cutoff rules are checked

Required information to gather

  • Transaction ID
  • Cancellation reason
  • Customer/payment details if needed

3. Step-by-Step Instructions

Step 1: Access the correct module

Open transaction history and access the completed transaction management view.

  1. Sign in with your Manager account.
  2. Open Sales History and find Completed Transactions.
  3. Confirm business date and terminal filter match the sale.

Tip: Verify filters and context before editing any records.

SCREENSHOT: Landing screen for Cancel a Completed Transaction

Step 2: Enter required details

Review eligibility and policy constraints

  1. Select the completed transaction targeted for cancellation.
  2. Open transaction details and check cancellation eligibility window.
  3. Enter mandatory cancellation reason.

Important: Incorrect values can cause policy or reconciliation issues.

SCREENSHOT: Data entry and selection fields for Cancel a Completed Transaction

Step 3: Validate the result

Execute cancel action with mandatory reason

  1. Review cancellation impact and reversal-status messages.
  2. Confirm payment reversal path (cash/card/digital) is valid.
  3. Resolve warning prompts before cancellation.
SCREENSHOT: Validation panel with totals and status checks

Step 4: Submit and confirm

Verify status changes and audit entry is created

  1. Execute Cancel Transaction and confirm the prompt.
  2. Confirm status changes from Completed to Cancelled.
  3. Verify audit log entry includes manager identity and reason.
SCREENSHOT: Success message with generated reference
